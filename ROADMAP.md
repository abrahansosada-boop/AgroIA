# ROADMAP.md — AgroIA fuera del prototipo

Última verificación: 2026-06-13
Objetivo: convertir AgroIA en una demo presentable, defendible y útil para usuarios reales del sector agro/pecuario.

## 1. North Star

AgroIA no debe quedarse como “una app de Streamlit que se ve interesante”.

La meta es convertirlo en un asistente de IA aplicado al campo que pueda:

* tomar datos técnicos de agricultura, ganadería, nutrición, sanidad o inventario;
* producir recomendaciones claras para un productor, técnico o estudiante;
* mostrar evidencia de dónde salió la recomendación;
* presentarse en hackathons, retos de innovación y eventos agro;
* evolucionar hacia pilotos reales con usuarios.

Pitch de una línea:

> AgroIA es un asistente de inteligencia artificial para productores y equipos agropecuarios que convierte datos técnicos en recomendaciones accionables, trazables y fáciles de entender.

## 2. Regla del proyecto

No se presenta AgroIA a ningún hackathon o convocatoria si no cumple este mínimo:

* Demo funcional de 3 minutos.
* Problema específico y usuario objetivo claro.
* Un dataset real, público o simulado de manera honesta.
* Flujo completo: pregunta → análisis → recomendación → evidencia.
* Repo instalable y ejecutable por alguien que no haya escrito el código.
* README con comandos para correr la app.
* Screenshots o video corto.
* Disclaimer cuando la recomendación toque temas veterinarios, nutricionales, sanitarios o financieros.
