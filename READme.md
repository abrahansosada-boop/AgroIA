# 🌾 AgroIA: Plataforma Integral de Ganadería Regenerativa y Zootecnia de Precisión

AgroIA es un ecosistema de software centralizado diseñado para la optimización operativa, financiera y biológica de explotaciones pecuarias. El sistema integra algoritmos de optimización matemática lineal y ecuaciones de balanceo nutricional para maximizar la capacidad de carga del rancho, reducir los costos de alimentación y mitigar riesgos climatológicos severos.

---

## 🧩 Módulos Principales del Sistema

El sistema está dividido en herramientas especializadas para cubrir todas las áreas críticas de un rancho moderno:

### 1. 📊 Panel Principal (Dashboard Ejecutivo)
* **Función:** Interfaz de visualización de Indicadores Clave de Rendimiento (KPIs, por sus siglas en inglés, que miden la salud y productividad del negocio) en tiempo real.
* **Componentes:** Resúmenes analíticos rápidos del estado de los inventarios, el número de animales y alertas operativas.

### 2. 🧪 Súper-Laboratorio Nutricional y Farmacológico
* **Motor de Formulación (Cuadrado de Pearson):** Algoritmo automatizado para balancear exactamente dos ingredientes forrajeros y alcanzar la meta de proteína ideal sin desperdiciar dinero.
* **Optimizador de Dietas (Mínimo Costo):** Algoritmo matemático avanzado que cruza múltiples ingredientes para crear la ración más barata posible cumpliendo con los requerimientos nutricionales del ganado.
* **Calculadora de Dosificación Farmacológica:** Automatización de cálculos de volumen de medicamento basado en el peso vivo del animal, evitando sobredosis y desperdicio de medicina.

### 3. 📦 Inventario Pecuario y Control de Insumos
* **Función:** Base de datos para el registro de activos biológicos (cabezas de ganado, lotes) e insumos agrícolas (forrajes, concentrados, medicamentos).
* **Almacenamiento Seguro:** Toda la información se guarda de manera permanente y segura en la nube (base de datos relacional) para que nunca pierdas tu información.

### 4. 👑 Bóveda Premium: Hub de Tecnologías Resilientes
Módulo avanzado y exclusivo diseñado para blindar al rancho contra sequías e inflación de insumos. 
* **Función:** Contiene protocolos operativos cerrados, manuales paso a paso y calculadoras de viabilidad financiera (ROI) de tácticas regenerativas de alto impacto traídas de los ecosistemas más adversos del mundo.
* **Pilares de Acción:** Supervivencia Hídrica y Alimentaria de Emergencia, Regeneración de Suelo a costo cero, y Manejo Dinámico Holístico. *(Acceso restringido a usuarios Premium).*

### 5. 🧮 Control de Peso (Báscula Analítica)
* **Función:** Registro continuado del peso de los animales para calcular automáticamente la Ganancia Diaria de Peso (GDP) y proyectar si el ganado está creciendo al ritmo adecuado para su venta.

### 6. 📉 Gestión de Mortandad
* **Función:** Auditoría sanitaria del hato. Registra las bajas y analiza estadísticamente las causas de muerte (patológicas o ambientales) para alertar al ganadero y tomar medidas preventivas antes de un brote.

### 7. 🗃️ Caja Negra (Bitácora de Auditoría)
* **Función:** Sistema de registro automático e inborrable que rastrea todas las entradas, salidas y movimientos de dinero o inventario realizados en la plataforma. Incluye un botón para descargar historiales completos a Excel (CSV).

## 🛠️ Stack Tecnológico 

* **Lenguaje Core:** Python 3.11+
* **Interfaz de Usuario (Frontend):** Streamlit
* **Gestor de Entornos y Dependencias:** `uv`
* **Gestión de Base de Datos:** Supabase (PostgreSQL)
* **Testing / Calidad (QA):** Pytest para pruebas unitarias.
